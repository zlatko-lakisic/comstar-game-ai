Keyed to the mockup

1Edge glow and state

Border glow sized to the game window, colour encoding what the agent is doing. The chip names the state in words so the colour never has to be memorised. Click through and never activates, or synthetic clicks land on it and the game silently does nothing.

2Virtual keyboard

Only the keys the agent actually uses: control groups, modifiers, pause, console, camera. Fades in on the first press and out after idle. Held modifiers stay lit while taps flash, because Ctrl held is what makes 2 mean group two.

3Cursor and intent preview

A ring follows the pointer. The dashed leash and hollow marker appear before the cursor travels, so you see what the agent is about to do rather than only what it did. Cyan is the agent driving; amber would mean you took the mouse.

4AO cycle window

The whole loop, not just traffic: what went up, live queue and phase from ReachRunStatus, the directive that came back with its latency, the intent it produced, and whether the action verified. This is the intent log, live.
